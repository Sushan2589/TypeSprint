# TypeSprint

This is a simple typing speed test platform built with HTML, CSS and JS all vanilla. High score system also exist to compete with yourself.

Passages are stored locally in passages.js only 15 passages are there right now.

It selects random passage from passages.js. Timer starts when beginning to type. WPM and Accuracy updates as you type.
Test ends in 60 seconds or if the paragraph is completed.

Best WPM saved in local storage.
